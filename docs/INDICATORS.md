# 📈 指标说明 & 实战解读指南

> 本文档解释系统中使用的每个技术指标的含义、数值解读和实战应用。

---

## 一、市场情绪指标

### 1.1 恐惧贪婪指数（Fear & Greed Index）

**数据源：** Alternative.me / Desk3 双源  
**取值范围：** 0 - 100  
**更新频率：** 每小时

| 分值区间 | 标签 | 含义 | 实战参考 |
|---------|------|------|---------|
| 0 - 24 | 😱 极度恐惧 | 市场恐慌严重，通常是积累期信号 | 🟢 买入机会区域 |
| 25 - 44 | 😰 恐惧 | 市场情绪低迷 | 🟢 适合定投 |
| 45 - 54 | 😐 中性 | 无明显方向 | ⚪ 观望 |
| 55 - 74 | 😎 贪婪 | 市场乐观 | 🟡 谨慎追涨 |
| 75 - 100 | 🤑 极度贪婪 | 市场泡沫风险区域 | 🔴 考虑分批减仓 |

**实战提示：**
- 恐惧贪婪是**反向指标**：极度恐惧时买入，极度贪婪时卖出
- 连续多天处于同一极端区域比单日极端值更有参考意义
- 当前系统记录了历史对比（昨日 / 上周 / 上月 / 年高 / 年低）

---

### 1.2 山寨季指数（Altcoin Season Index）

**数据源：** Desk3 API  
**计算逻辑：** BTC 前 10 以外的币种中，有多少比例在最近 30 天跑赢 BTC  
**取值范围：** 0 - 100

| 分值 | 含义 | 实战参考 |
|------|------|---------|
| 75+ | 🔥 山寨牛市 | 山寨币全面启动，仓位可偏向山寨 |
| 50 - 74 | 📈 山寨季 | 资金开始扩散，关注主流山寨 |
| 25 - 49 | 🌙 山寨熊市 | 资金集中在 BTC，减少山寨仓位 |
| < 25 | ❄️ 深度熊市 | 山寨熊市，专注 BTC |

**实战提示：**
- 山寨季指数 > 75 是减仓山寨、增持 BTC 的信号
- 结合 BTC 主导率一起看：两者同时指向山寨季 = 强确认

## 二、周期指标

### 2.1 Puell 倍数（Puell Multiple）

**数据源：** Desk3 API  
**计算：** 矿工每日收入（USD）/ 365 天移动平均值  
**核心逻辑：** 矿工是天然的 BTC 卖家（需要支付电费）。当矿工收入远低于年均值时，被迫低价卖出 = 积累信号；当远高于均值时，矿工大规模卖出 = 顶部信号。

| Puell 值 | 含义 | 信号 |
|---------|------|------|
| < 0.5 | 极度低估 | 🟢 **最佳买入时机** |
| 0.5 - 1.0 | 低估 | 🟢 持续买入 |
| 1.0 - 2.0 | 正常 | ⚪ 无特别信号 |
| 2.0 - 4.0 | 高估 | 🟡 谨慎 |
| 4.0 - 6.0 | 极度高估 | 🔴 考虑减仓 |
| > 6.0 | 历史顶部区域 | 🔴 **周期顶部警告** |

**实战提示：**
- Puell < 0.5 是系统内最强烈的买入信号之一
- 结合 30 个周期指标一起看：`cycle-indicators.mjs`

---

### 2.2 Pi Cycle 顶部指标（Pi Cycle Top）

**数据源：** Desk3 API  
**计算：** 111 日移动平均线（MA111）与 2 倍 350 日移动平均线（MA350×2）的交叉

**信号逻辑：**
- 当 BTC 价格快速上涨时，MA111 会向上穿越 MA350×2 → 触发交叉 = 周期顶部警告
- 历史准确率：在 2013 年、2017 年、2021 年顶部都成功预警

| 状态 | 信号 |
|------|------|
| MA111 < MA350×2 | ✅ **未交叉 — 安全** |
| MA111 > MA350×2 | ❌ **已交叉 — 警惕周期顶部** |

**实战提示：**
- Pi Cycle 是**长周期指标**，不适用于短期交易
- 一旦交叉，下一个周期内不会再交叉（需等待下一个减半周期）
- 每周减半后重新评估（当前系统默认每周检查）

---

### 2.3 MVRV Z-Score

**数据源：** Desk3 cycle-indicators  
**计算：** (Market Cap - Realized Cap) / StdDev(Market Cap)  
**含义：** 衡量 BTC 当前市值相对于"实际成本基础"的偏离程度

| Z-Score | 含义 |
|--------|------|
| < 0 | 市值低于实际成本 → 折价 |
| 0 - 3 | 正常区间 |
| 3 - 7 | 高估，开始积累风险 |
| > 7 | **极度高估，历史顶部区域** |

---

### 2.4 Ahr999 指数

**数据源：** Desk3 cycle-indicators  
**含义：** 融合价格、200 日定投收益、BTC 减半稀缺性的复合指标

| Ahr999 | 含义 |
|--------|------|
| < 0.45 | 🟢 极佳买入时机 |
| 0.45 - 1.2 | 🟢 适合定投 |
| 1.2 - 2.4 | ⚪ 中性 |
| > 2.4 | 🟡 价格偏高 |

## 三、链上指标

### 3.1 BTC 主导率（BTC Dominance）

**数据源：** Desk3 API  
**含义：** BTC 市值占全加密货币总市值的比例

| 主导率 | 市场阶段 | 含义 |
|--------|---------|------|
| > 60% | BTC 防御模式 | 资金避险，情绪偏谨慎，山寨压力大 |
| 50% - 60% | BTC 主导 | 正常状态 |
| 40% - 50% | 过渡阶段 | 资金开始扩散 |
| < 40% | 山寨活跃 | 山寨季启动，资金涌入山寨 |

**配合指标：**
- BTC 主导 + 山寨季指数同时上升 = 山寨季确认
- BTC 主导 + 恐惧贪婪同时低位 = 积累期信号

---

### 3.2 BTC / ETH 网络趋势（算力 & 难度）

**数据来源：** Desk3 API（`/market/btc/trend`、`/market/eth/trend`）  
**数据格式：** `[date, price, hashrate(EH/s), difficulty(T)]`

| 指标 | 说明 | 信号 |
|------|------|------|
| 算力/难度比（HR Ratio）| > 2.5 = 算力充沛 | 🟢 牛市信号 |
| | < 2.0 = 算力紧张 | 🔴 熊市信号 |
| 7日算力变化 | 正增长 | 矿工信心增强 |
| 难度变化 | 正增长 | 网络健康，算力跟上 |

**实战提示：**
- 算力是 BTC 的**领先指标**：矿工在价格上涨后才会增加算力投入
- 难度骤降（-10% 以上）通常是周期底部信号

## 四、品种筛选指标（coin-screener.mjs）

### 4.1 RSI（相对强弱指标）

**取值范围：** 0 - 100  
**计算周期：** 系统使用 4h RSI（主力）和 24h RSI（备选）

| RSI 值 | 含义 | 信号 |
|--------|------|------|
| < 25 | 极端超卖 | 🟢 强做多信号 |
| 25 - 35 | 普通超卖 | 🟢 做多参考 |
| 35 - 45 | 弱势 | 🟡 参考 |
| 45 - 55 | 中性 | ⚪ 无信号 |
| 55 - 70 | 偏强 | ⚪ 无信号 |
| 70 - 80 | 超买 | 🔴 做空参考 |
| > 80 | 极度超买 | 🔴 强做空信号 |

**实战提示：**
- RSI < 30 + 资金费率极负 = 双重做多信号（最强组合）
- RSI > 80 + 资金费率极高 = 双重做空信号
- 不要单独用 RSI，务必结合其他指标

---

### 4.2 资金费率（Funding Rate）

**含义：** 多空双方每隔 8 小时相互支付的费率（由交易所收取）  
**交易所来源：** Binance、OKX、Bybit、Deribit 等主流交易所

| 资金费率 | 含义 | 信号 |
|---------|------|------|
| < -1.0% | 极度负（空头挤压）| 🟢 **强做多信号** |
| -0.3% ~ -1.0% | 负（偏空）| 🟢 做多参考 |
| -0.3% ~ +0.3% | 中性 | ⚪ 无信号 |
| +0.3% ~ +1.0% | 正（偏多）| 🔴 做空参考 |
| > +1.0% | 极度正（多头挤压）| 🔴 **强做空信号** |

**核心逻辑：**
- 资金费率 > 0 = 多头给空头钱（多头者众多，市场过热）
- 资金费率 < 0 = 空头给多头钱（空头者众多，容易轧空暴涨）
- **资金费率极负 + 价格暴涨 = 轧空尾声（风险！要小心）**

**历史案例：** 2021 年 5 月 19 日、2022 年 11 月多次出现资金费率极负后的轧空行情。

---

### 4.3 OI（持仓量 / Open Interest）

**含义：** 某个币种所有未平仓合约的总价值  
**单位：** USDT 或 USD

| OI 变化 | 价格变化 | 综合信号 |
|---------|---------|---------|
| 增 | 涨 | ✅ **真突破**（新资金推动）|
| 增 | 跌 | ✅ **真跌破**（新资金做空）|
| 减 | 涨 | ⚠️ **假突破**（存量拉盘）|
| 减 | 跌 | ⚠️ 多头去杠杆（未必见底）|

**Price-OI 分歧信号详解：**
```
信号：价格涨 + OI 降 = 假突破 ⚠️
原因：没有新资金入场，只是存量资金拉盘。
      一旦拉盘力量减弱，价格会快速回落。
处理：不要追高，等回踩确认再介入。

信号：价格涨 + OI 增 = 真突破 ✅
原因：新开多单推动价格上涨，趋势有持续性。
处理：可以顺势跟进，但严格止损。
```

---

### 4.4 多空比（Long Short Ratio）

**含义：** 大账户多头持仓 / 空头持仓的比例  
**区分：** 持仓多空比（资金量）vs 人数多空比（用户数）

| 多空比 | 含义 | 信号 |
|--------|------|------|
| < 0.7 | 极度偏向空头（散户做空）| 🟢 利于轧空 |
| 0.7 - 0.9 | 偏空头 | 🟢 做多参考 |
| 0.9 - 1.1 | 均衡 | ⚪ 无信号 |
| 1.1 - 1.5 | 偏多头 | 🔴 做空参考 |
| > 1.5 | 极度偏向多头（散户做多）| 🔴 市场顶部警告 |

**实战提示：**
- 看**大账户持仓多空比**，而不是人数多空比
- 人数多空比 > 持仓多空比 = 散户做多、大户做空 = 反向信号

---

### 4.5 爆仓热力图

**含义：** 显示多空双方爆仓密集发生的价位  
**单位：** 通常以 USD 或 USDT 表示

| 情况 | 信号 |
|------|------|
| 空头爆仓密集 > 多头爆仓密集 | 🟢 利于继续做多（空头被迫平仓，推动价格上涨）|
| 多头爆仓密集 > 空头爆仓密集 | 🔴 利于做空（多头被迫平仓，推动价格下跌）|
| 爆仓金额巨大 | ⚠️ 极端行情，波动加大 |

**注意：** 爆仓热力图识别的是**支撑/阻力价位**，而非方向。爆仓密集区往往是未来价格波动的关键节点。

## 五、综合评分解读

### 评分体系（coin-screener.mjs）

| 综合评分 | 信心等级 | 信号强度 | 建议 |
|---------|---------|---------|------|
| 55+ 分 | ⭐⭐⭐ 强信号 | 非常强 | 可考虑建仓，严格止损 |
| 40 - 54 分 | ⭐⭐ 中信号 | 中等 | 轻仓试探 |
| 25 - 39 分 | ⭐ 弱信号 | 较弱 | 观望或极轻仓 |
| < 25 分 | — 无信号 | 不足 | 不操作 |

### 风险等级

| 等级 | 含义 | 建议 |
|------|------|------|
| 🟢 低风险 | 多指标共振偏低，趋势温和 | 可正常仓位 |
| 🟡 中风险 | 某一指标极端但未到极限 | 降低仓位 |
| 🔴 高风险 | 多指标同时极端（暴涨/超买等）| 极高仓位需谨慎 |

## 六、实战指标组合

### 🟢 最强做多信号组合
```
恐惧贪婪 < 30（极度恐惧）
+ RSI < 30（超卖）
+ 资金费率 < -0.5%（空头挤压）
+ Puell < 1.0（估值低估）
+ Pi Cycle 未交叉（安全）
→ 综合评分 55+ = ⭐⭐⭐ 强信号
```

### 🔴 最强做空信号组合
```
恐惧贪婪 > 70（极度贪婪）
+ RSI > 75（超买）
+ 资金费率 > +0.5%（多头挤压）
+ Puell > 4.0（极度高估）
+ Pi Cycle 已交叉
→ 综合评分 55+ = ⭐⭐⭐ 强信号
```

### ⚠️ 需要谨慎的信号
```
资金费率极负(-1.0%以下) + 价格暴涨(+50%以上)
→ 这是"轧空尾声"而非做多机会！
→ 系统会自动加高风险标签
```
